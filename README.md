# Dark Mode for Kansas Connections Academy

A Tampermonkey userscript that adds a dark theme to the KCA platform, since staring at a bright white screen all day just ain't it.

![screenshot](screenshots/before-after.png)

## Features
- Dark theme applied across most KCA pages (dashboard, gradebook, assignments)
- No more flash bangs late at night
- Lightweight — just CSS/JS injected via Tampermonkey, **DOES NOT** touch your account or data

## Installation
1. Install the [Tampermonkey](https://www.tampermonkey.net/) browser extension
2. Click this link to install the script: [kca-dark-mode.user.js](link-to-raw-file)
3. Tampermonkey will prompt you to confirm — click **Install**
4. Refresh your KCA dashboard and you're good to go
